# MediBot

A friendly health chatbot that works offline, shows pictures, looks things up on Wikipedia and learns from conversations.

**Live site:** https://oonnosfjsjfie.github.io/medibot/

- `index.html`: the bot (design at the top, code below)
- `knowledge.js`: 291 built-in health topics
- `config.js`: Firebase settings for the learning memory

*General health information only, not a diagnosis. In an emergency, call 108 or 112.*
